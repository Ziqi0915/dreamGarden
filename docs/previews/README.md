# 毛绒花园 · 实际效果

这里展示当前程序在浏览器中的实际渲染效果，区别于 [风格概念图](../concepts/README.md)。

兔子采用选定预览图中的大头、短身、短四肢比例。第一个场景使用短绒纤维、布料纹理、毛毡花草和柔软绒簇地面；保留花环、背带裤缝线和蜜蜂装胡萝卜。
